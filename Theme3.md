### №5
### Напишите программу, в которой циклом for значения переменной і будут меняться от 0 до 10 и посмотрите, как разные виды сравнений и операций работают в цикле.
### Ответ:
```python
for i in range(10):
    print ("i = ", i)
    if i == 0:
        i += 2
    if i == 1:
        continue
    if i == 2 or i == 3:
        print("Переменная равна 2 или 3")
    elif i in [4, 5, 6]:
        print("Переменная равна 4, 5 или 6")
    else:
        break
```

### Вывод: В данном коде благодаря циклу for и условиям меняется значение переменной i до того, пока цикл не закончится.

### Ответ:
```python
string = "Привет всем изуающим Python!"

        index = string.find(value)
        print(f"Буква '{value}' есть в строке под {index} индексом")
```

```python
value = 0
```

### №10
### Напишите программу с использованием flag, которое будет определять есть ли нечетное число в массиве. В данной задаче flag выступает в роли индикатора встречи нечетного числа в исходном массиве, четных чисел.

### Ответ:
```python
even_array = [2, 4, 6, 8, 9]
flag = False
for value in even_array:
    if value % 2 == 1:
        flag = True

if flag is True:
    print("В массиве есть нечетное число")
else:
    print("В массиове есть числа четные")
```

### Вывод: В данном коде показано как можно пользоваться flag для определения выполнения условия в цикле for.
