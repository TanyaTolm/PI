### Ответ:
```python
def tuple_sort(tpl):
    for elm in tpl:
        if not isinstance(elm, int):
            return tpl
    return tuple(sorted(tpl))

if __name__ == '__main__':
    print(tuple_sort((5, 5, 3, 1, 9)))
    print(tuple_sort((5, 5, 2.1, "1", 9)))
```
![Меню]()

### Вывод: В этом коде происходит сортировка кортежа от наименьшего к наибольшему, только когда в нем только целые числа. В противном случае выводит первоначальный кортеж.
